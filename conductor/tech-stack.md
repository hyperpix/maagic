# Technology Stack

## Core Frameworks
- **Frontend:** Next.js (App Router) - For building a fast, scalable, and modern web application with TypeScript support.
- **Real-time Backend:** Convex - Handles the database, serverless functions, and real-time subscriptions with a single, cohesive developer experience.

## Language
- **TypeScript:** Ensuring type safety across the entire stack, from frontend components to backend functions.

## UI & Styling
- **CSS Framework:** Tailwind CSS - For rapid, utility-first styling.
- **Component Library:** shadcn/ui - A collection of re-usable components built with Radix UI and Tailwind CSS, following the project's minimalist design goals.
- **Icons:** Lucide React - A clean and consistent icon set that integrates well with shadcn/ui.

## Package Management
- **npm / bun:** Standard package management for the Node.js ecosystem.
